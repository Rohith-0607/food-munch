# Food Munch 🍔🍕

Food Munch is a fully responsive restaurant & food delivery landing page built with **HTML5**, **CSS3**, and **Bootstrap 4**.

## 🌟 Features

- **Responsive Navigation Bar**: Fixed header with brand logo, smooth collapse toggle, and navigation links.
- **Hero / Banner Section**: Eye-catching call-to-action banner with food imagery and action buttons (*View Menu*, *Order Now*).
- **Why Choose Us?**: Highlights service quality, fresh ingredients from partner farms, and exclusive promotional offers.
- **Explore Menu**: Card-based grid showcasing various food categories (Veg/Non-Veg Starters, Soups, Seafood, Main Course, Desserts, etc.).
- **Healthy & Organic Food**: Informational showcase emphasizing organic farm-fresh produce.
- **Delivery & Payment Section**: Outlines delivery perks, live tracking, and accepted payment options (Visa, MasterCard, PayPal, Amex).
- **Customer Appreciation & Gift Voucher Modal**: Interactive Bootstrap modal enabling customers to redeem special discount vouchers.
- **Social Follow & Footer**: Quick links to social media and restaurant contact information.

## 🛠️ Built With

- **HTML5**
- **CSS3** (Custom typography, responsive card grids, hover effects, and radial gradients)
- **Bootstrap 4.5.2** (Grid system, navbar, cards, modal components)
- **Font Awesome** (Social media icons)
- **Google Fonts** (Roboto, Bree Serif, Caveat, etc.)

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Rohith-0607/food-munch.git
   ```
2. Navigate into the project folder:
   ```bash
   cd food-munch
   ```
3. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
